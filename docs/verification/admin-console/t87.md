# T87 · 공고 본문 이미지 저장

## 요구사항과 책임

텍스트 본문에 선택한 이미지만 저장하고, 수정·삭제·저장 실패 시 파일 수명도 공고와 함께 관리한다.

```text
HTTP multipart → Service(트랜잭션·보상)
                    ↓
        AnnouncementBodyImages(소유 이미지 참조 검증·HTML 조립)
                    ↓
        Announcement(본문·파일 목록) → DB
                    └→ FileStorage(파일 저장·삭제)
```

- `bodyImages`는 반복 multipart 파일, HTML의 `attachment:0`은 요청 파일의 순번이다. 외부 HTML 이미지는 자동 수집하지 않는다.
- 수정 시 기존에 소유한 이미지와 새 파일만 허용한다. 저장한 이전 URL이 CDN 설정 변경으로 달라지면 소유 파일 키를 확인하고 현재 URL로 바꾼다.
- 제거한 파일은 DB commit 후 삭제하고, 저장 실패 시 새 업로드를 보상한다. 기존 일반 게시글 sanitizer 정책은 유지한다.
- 클래스·메서드 이름과 호출부 검토: `prepare`, `upload`, `compensate`를 실제 효과에 맞게 분리했고 서비스가 유스케이스/트랜잭션을 소유한다. HTTP 필드 `content`, `accessUrl` 호환 유지. Vue/TS 변경 검증은 T88에 기록한다.
