# 부트텐트 교육 필터 조사와 DEMP 적용

2026-09-27, https://boottent.com/camps 의 목록과 상세 필터를 현재 cmux browser surface:13에서 직접 열어 확인했다. 앞선 Firecrawl 목록 추출도 참고했다.

- 실제 상세 필터: 온라인/오프라인, 전국 시도/해외, 내일배움카드/카드 없는 무료/유료, 파트타임/풀타임, 코딩 포함/미포함/선발 없음, 학습 목적별 추천대상.
- 목록 비교 정보: 모집 상태, 교육비, 수업 방식, 학습 시작/종료·기간, 요일/시간, 기술 키워드, 채용 연계, 운영 기업.
- 지원 유형과 실부담금은 다르다. 공개 목록에 KDT 40~60만원과 무료 과정이 함께 있다. DEMP는 국비 지원을 무료로 추정하지 않는다.

## 적용

DEMP 개발 직무·기술 선택은 유지하고, 교육 전용 상세 조건을 저장/검색/표시 전 구간에 연결한다. 주관적인 추천 문구는 복제하지 않고 학습 수준(입문/기초 경험 필요/심화/무관)과 선발 방식으로 구분한다. 원문에서 확인하지 못한 정보는 null로 유지하고 어떤 조건에도 임의 매칭하지 않는다.

금액: payment=null 미확인, 교육의 0=무료, 양수=본인 부담 교육비(만원). 채용은 별도의 salaryStatus와 상한으로 연봉 미공개/협의/금액 범위를 표시. 연봉 검색은 제공하지 않는다.

교육 정보: 온라인/오프라인/혼합, 지역, 풀타임/파트타임/자율, 내일배움카드/기타 국비/기관 지원/자비, 코딩 포함/코딩 없음/선발 없음, 학습 수준, 교육 시작일/종료일. 모집 기간과 교육 기간은 분리한다. 기간 검색은 정확한 일수 구간으로 제공한다.
