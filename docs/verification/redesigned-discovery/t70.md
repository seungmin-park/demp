2026-09-27, 양쪽 `refactor/redesigned-discovery-and-bootcamp-filters`. 기준 B3da14a5/F ac5b7fd. 작업 경로는 이 문서의 [계획](plan.md), 기준은 [디자인 결정](../../design/redesigned-discovery.md).

## 변경과 책임

```text
작성 페이지 → MarkdownEditor (입력·선택·도구·보기)
    ↓ 저장                 ↓ 미리보기
renderMarkdown → sanitizeHtml → SafeHtml
    ↓ API                    ↓ 안전한 화면
서버 ContentSanitizer → DB HTML 저장
```

- ZIP의 인디고/흰색/회색, 간격과 둥근 모서리를 CSS 토큰으로 통일. 헤더·로그인·가입·공고/질문 목록·상세·작성·답변을 재구성. 이름은 DEMP. 중첩 body/main, 고정 폭·높이, 전역 td/p 스타일 제거. 화면 조립은 View, 데이터 요청은 기존 API 모듈을 유지.
- MarkdownEditor는 문자열 props/event와 커서 조작만 소유한다. 페이지가 저장 상태와 API를 조정한다. `renderMarkdown`, `markdownFromHtml`, `sanitizeHtml`은 파싱·레거시 HTML 변환·안전성의 서로 다른 책임을 갖는다. 기존 밑줄/표 HTML 왕복 및 XSS 정책 검증. 서버도 같은 안전한 제목/표/취소선 서식을 허용한다. 저장 계약은 HTML 그대로다.
- Summernote/jQuery CDN과 Bootstrap/Popper 의존성 제거. 외부 에디터 로딩에 의존하지 않는다.
- MemberBadge/ContentReactions/AppIcon은 표시 전용 props로 통일. 서버가 지원하지 않는 추천 저장은 비활성 유지. 조회·추천 숫자는 서버 값, accessible name 제공. CompanyImage는 이미지 실패 시 DEMP 대체 표시를 담당한다.
- `formatLanguages`: `JAVA, SPRING` 배열 → 화면의 `Java, Spring` 문자열. 따옴표/괄호/칩 없음. `formatRecruitDate`: 서버 LocalDateTime의 날짜·시각을 직접 조립해 `2026.09.01 09:00`, 빈값은 일정 미정. API 배열·enum·날짜 원문과 시간대는 바꾸지 않는다.
- 변경한 이름과 호출부 검토: 변환 함수 이름은 반환값/효과를 표시한다. 기존 공개 props/event/API/라우트는 유지. Vue는 렌더링·상태·API 경계로 검토했고 독립 TS 모듈은 한 가지 변경 이유를 유지한다. 불필요한 서비스/인터페이스는 추가하지 않았다.
