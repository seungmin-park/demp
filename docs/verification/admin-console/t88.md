# T88 · 서식 편집과 원문 이동

## 변경과 책임

Tiptap 기반 공고 전용 편집기: 채용/교육 항목 삽입, 제목·강조·목록·링크, 파일 선택/붙여넣기/드롭, 모바일 미리보기. 붙여넣은 텍스트 서식은 정돈하고 외부 이미지는 자동 복제하지 않는다. 파일은 저장할 때 함께 전송한다.

```text
편집기 → HTML + File[] → 폼 검증 → API multipart → T87 저장
                                       ↓
상세 화면 ← 저장 후 별도 조회 ← 서버 HTML/이미지 URL
    └ 지원하기 → accessUrl 원문 새 탭
```

- Vue는 입력/표현과 이벤트, `announcementAttachments.ts`는 첨부 규칙, API 모듈은 HTTP 변환을 담당한다. 이름/호출부와 props/event 계약을 검토했다. 일반 게시글의 이미지 정책은 변경하지 않았다.
- 파일당 5MB, 본문 최대 10개, 대표 이미지 포함 합계 9MB. 서버 multipart 10MB 중 요청 메타데이터 여유를 둔다. 파일 MIME/빈 파일도 폼과 편집기 경계에서 검사한다.
- 실패 시 본문/첨부 유지, 기존 이미지 재조회 보존, blob URL 해제. 원문 URL의 새 탭 보안 속성 유지.
