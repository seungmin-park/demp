# DEMP 외부 공고 운영 정책

## 현재 운영
운영자가 원문을 확인해 요약·구조화 정보를 등록한다. 기업·교육기관의 직접 제출, 자동 크롤러, 광고 상품은 현재 도입하지 않는다. 따라서 소속 승인/반려·재제출은 도입 조건이 충족될 때 설계할 후속 항목이다.

초안 → 검토 중 → 공개 → 비공개는 게시 상태다. 모집 종료는 독립 표시이며 공개 기록을 보존한다. 자동 동기화가 없으므로 운영자 수정이 외부 내용에 덮이지 않는다. 출처·확인 여부·기수·지원금 등 미확인 정보는 빈값을 유지한다. 변경 발견 시 원문을 다시 확인하고 편집·확인 체크 후 저장한다. 사용자 오류 제보는 운영 화면에서 원문 확인/공고 수정 후 처리 내용을 기록한다.

지원하기는 별도 지원 URL이 있으면 해당 외부 주소, 없으면 원문 주소로 이동한다. 수동 마감 시 원문 확인으로 표시한다. 원문 콘텐츠 전체 복제보다 직접 정리한 요약을 기본으로 하고 이미지 사용 권한과 출처 표기를 운영자가 확인한다.

## 이미지 유지·재사용·크롭 결정
- 대표 이미지는 선택 업로드. 미등록 또는 로딩 실패 시 DEMP 기본 표시.
- 기관 로고는 contain으로 비율을 보존하며 자동 헤더 크롭을 적용하지 않는다. 상세 본문 이미지는 최대 가로폭 내 비율 보존.
- 본문 이미지 파일·붙여넣기·드래그 업로드는 유지한다. 외부 페이지 이미지를 자동 수집하지 않는다.
- 기관 공용 로고 라이브러리는 미도입. 같은 로고를 여러 공고에 쓰려면 각 공고에 독립 업로드하여 각 파일의 삭제 수명주기를 유지한다. 저장 키를 수동 공유하지 않는다. 공유 저장을 도입할 때 기관 자산 소유권과 참조 수명주기를 먼저 구현한다.
- 현행 로컬 FileStorage/S3 경계는 유지. 이 작업의 검증은 H2/로컬 파일만 사용했다.

## 수동 스키마 반영
기존 manual SQL에 이어 announcement-publication.sql을 한 번 적용한다. 기존 공고는 PUBLISHED, 모집 종료 false, 새 메타데이터는 NULL이다. 기존 중복 공고는 보존하며 자동 삭제하지 않는다. duplicate_key가 없는 기존 행은 등록·수정 사전 비교로 중복을 감지한다. 배포 전 백업과 스키마 적용은 별도 운영 절차이며 이번 로컬 작업에서 운영 DB에 실행하지 않았다.
