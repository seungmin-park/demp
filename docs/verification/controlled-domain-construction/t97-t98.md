이름·책임 검토: AnnouncementReport 생성 시각 인자를 now→createdAt으로 명확히 했다. 생성 검증은 도메인, HTTP 변환은 DTO, 트랜잭션·권한·관계 조정은 기존 Service/소유 객체에 남는다. 생성자 대신 builder를 호출하는 모든 production/test 호출부를 컴파일로 확인했다. 별도 위임 객체나 인터페이스는 추가하지 않았다. 이번 변경은 Java만 해당하며 Vue/TypeScript 수정 없음.
