# T71 채용·부트캠프 필터

## 요구사항 → 결정

[국내 사례 조사](../../design/redesigned-discovery.md)를 기반으로 전체/채용/부트캠프, 직무·기술·모집상태·경력·최소 연봉, 교육 무료/유료, 회사/기관·제목 검색을 구현했다. 선택 칩·개별 해제·모드 유지 전체 초기화·모바일 펼침을 제공한다.

현재 DB의 payment는 채용 연봉 또는 교육비(만원), 0원 교육은 무료다. 교육방식/수업기간/지역/고용형태는 저장된 정보가 없어 노출하지 않는다. 해당 정보는 추측하지 않으며 스키마 변경이 필요할 때 저장/작성/검색을 함께 추가한다. 따라서 이번 작업은 DB 컬럼 변경·마이그레이션이 없다.

```text
URL ↔ 필터 DTO → API 쿼리 → DB 전체 조건 검색
                         ↓
              ID 페이지 → 언어 일괄 조회 → 카드
```

기술·직무 그룹 내부는 OR, 다른 그룹은 AND. 기존 단일 language는 호환 유지하고 languages를 추가했다. 제목/회사명은 대소문자를 무시한다. 모집중은 시작≤한국시각≤마감, 예정은 시작 이후, 마감은 종료시각 이전. Clock을 주입해 경계 시각을 테스트에서 고정했다. 무료/유료는 EDU만 적용한다.

## 책임·공개 계약

- `filtersFromQuery`/`filtersToQuery`는 URL 해석·정규화를 담당한다. enum 목록 밖의 값, 잘못된 숫자는 요청하지 않는다. Header는 조작, List는 페이지/요청 세대/중복 방지, API 모듈은 HTTP 변환을 맡는다. 저장용/표시용 enum은 분리했다.
- `recruitmentMatches`, `tuitionMatches`, `languagesIn`은 DB 조건을 표현한다. TimeConfiguration은 시계 경계 하나만 제공한다. 추측성 인터페이스를 추가하지 않았다.
- 목록 응답에 회사, 유형, 경력 범위, 금액, 모집 기간을 추가하고 REST Docs와 TS 타입을 함께 갱신했다. 기존 필드를 제거하지 않았다. 카드의 숫자는 서버 데이터다.
- 무료 교육 등록의 UI 최소값 2400은 서버 `@Min(0)`와 충돌했다. 실제 검증 실패를 확인하고 0으로 맞췄다.
