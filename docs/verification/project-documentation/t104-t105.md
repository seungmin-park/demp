### 현재 cmux 실제 브라우저

호출 정보 `cmux identify --json`: workspace:2 / pane:3 / surface:3. 현재 시각적 포커스가 workspace:3이어도 호출 workspace:2를 대상으로 사용했다. 기존 검증 pane이 닫혀 오른쪽 pane:15, terminal surface:38, browser surface:39를 만들었고 다른 workspace에 명령을 보내지 않았다.

터미널에서 최신 성능 수정 JAR를 로컬18080에 실행하고 프런트5050과 연결했다. 별도 Chromium headed Playwright는 API fixture이고, 아래 내장 브라우저는 실제 Spring 임시 H2다.

1. 서버 교체 중 상세 요청 실패 화면에서 실제 재시도 버튼을 클릭해 복구.
2. 실제 질문 상세의 본문·작성자·태그·답변 렌더링 확인.
3. 질문 추천, 답변 비추천 버튼 클릭 → 새로고침.
4. DOM assertion으로 `추천1/선택, 비추천0/해제, 추천0/해제, 비추천1/선택` 확인.
5. 질문 비추천으로 전환한 뒤 같은 버튼으로 취소 → 새로고침. DOM assertion으로 질문 추천0/비추천0 모두 해제, 답변 비추천1 선택 유지 확인. 두 실제 브라우저 assertion 모두 PASS.

사용 중인 브라우저 하나와 검증 로그 pane을 유지했다. 단순 화면 캡처를 자동 E2E로 부르지 않는다.
