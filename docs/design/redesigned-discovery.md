## 상태·책임·검증

```text
URL 조건 ↔ 화면 필터 → 타입 있는 API 요청 → 서버 전체 데이터 조건 검색
                        ↓                  ↓
                  현재 요청 세대 확인 ← 페이지 결과
                        ↓
                중복 ID 제거 → 카드 목록
```

페이지 끝 감지는 IntersectionObserver, 요청/필터 상태는 목록 상태 관리, HTTP 변환은 API 모듈이 맡는다. 필터를 바꾸면 페이지와 결과를 초기화하고 이전 세대 응답을 버린다. 로드된 일부 카드만 클라이언트에서 걸러 전체 검색처럼 보이게 하지 않는다.

- 필수 화면: 공고/부트캠프 목록·상세·작성, 로그인·가입, 질문 목록/검색·작성·상세·답변, 404·403·로딩·빈 결과·오류 재시도.
- 관리 화면: 운영 현황, 공고/부트캠프 CRUD, 질문/답변 조회·관리, 관리자 401/403·권한 회수. 서버의 역할 검증을 필수로 한다.
- 동작: URL 복원·뒤로 가기·다중 필터·인피니티 스크롤·응답 역전·재시도·최종 페이지·중복 방지.
- 디자인: ZIP 일관성, DEMP 이름, 모바일 overflow, 대비·focus-visible·reduced-motion·터치 영역, 긴 제목/빈 이미지/없는 값 처리.


## 추가 요구: 작성 화면과 Markdown 에디터

기존 textarea/table/Summernote 화면을 폐기하고 ZIP 토큰을 사용하는 공통 작성 화면과 MarkdownEditor를 만든다. 제목/본문/태그를 별도 섹션으로 구분하고 글쓰기·미리보기·데스크톱 분할 보기, 제목·강조·목록·링크·코드 도구, 모바일 하단 저장 영역을 제공한다. 도구 모음은 키보드와 스크린리더 레이블을 지원하며 텍스트 삽입 후 선택·커서 위치를 보존한다. Markdown→HTML 미리보기는 기존 SafeHtml 정화 경계를 통과한다. 저장 포맷·기존 HTML 재편집 호환성을 먼저 테스트로 고정하고 API와 함께 결정한다. 관리자 공고 편집에도 같은 작성기를 재사용한다.

## 추가 요구: 추천·비추천·조회수·회원 아이콘

이모지(👍/👎/👁/🙋‍♂️)를 일관된 SVG 아이콘으로 교체한다. 선 굵기·20px 기준 크기·숫자 간격을 통일하고, 추천/비추천은 버튼의 hover/focus/선택/비활성 상태를 구분한다. 조회수는 읽기 전용 정보로 표현한다. 회원 표시에는 기본 아바타와 계정 메뉴를 사용한다. 아이콘만 있는 버튼에는 한국어 접근 가능한 이름을 제공한다. 서버에서 지원하지 않는 반응 저장을 동작하는 것처럼 꾸미지 않고 실제 제공 상태를 명확히 표시한다. 질문 목록·상세·답변·헤더의 표현을 함께 맞춘다.

## T70 구현 전 점검

ZIP은 로그인·가입·목록·상세·작성 템플릿을 제공하지만 글쓰기 표 배치/Summernote, 질문 목록 전역 스타일, 모바일·404·오류 상태가 미완성이다. 공통 헤더/색상/카드 토큰을 기준으로 쓰고 기능 코드는 이식하지 않는다. 작은 카드마다 그림자를 주는 대신 결과 카드에만 흰 표면·경계를 쓰며 본문과 작성기는 넓은 문서 영역으로 구성한다. 제목은32px/본문16px·1.7행간, 모두 왼쪽 정렬. 조회/추천/비추천은 SVG와 숫자를 같은 기준선에 놓고 회원은 기본 아바타로 표시한다.

작성기: 제목 → toolbar → Markdown 입력/미리보기 → 태그 → 제출. 1080px 페이지 안에서 작성기를 넓게 쓰고 모바일은 한 열로 읽고 쓸 수 있게 한다. 편집 상태는 컴포넌트, 변환은 TS 모듈, 정화는 공통 HTML 정책, 저장은 부모의 API 유스케이스로 분리한다. 기존 content HTML 저장 계약을 유지한다. 초기 HTML→Markdown에는 밑줄/표 등 CommonMark 밖의 안전한 HTML을 보존하며 변환 전후 정화를 거친다.

공식 확인: [marked](https://marked.js.org/)는 HTML 정화를 제공하지 않아 출력 DOMPurify가 필수다. [Turndown](https://github.com/mixmark-io/turndown)의 atx/fenced 옵션과 keep 규칙으로 기존 서식을 보존한다. registry 확인 marked18.0.14(Node>=20), turndown7.2.4(Node>=18), types5.0.6; 프로젝트 Node24와 호환.

브리프 대조: 인디고/둥근 표면은 사용자 ZIP의 명시적 기준이라 유지한다. ZIP의 큰 고정 편집기 폭·표 폼·이모지는 사용자 추가 지시와 충돌하므로 responsive grid·공통 Markdown toolbar·SVG로 바꾼다. 의미 없는 통계/추천 공고/기능 없는 지원 버튼을 새로 만들지 않는다.

추가 표시 요구: 기술 enum 배열은 API 그대로 문자열화하지 않고 `Java, Spring`처럼 쉼표로 구분해 표시한다. 모집 기간의 LocalDateTime은 화면에서 `2026.09.27 09:00`처럼 보이고, 기계 판독용 time.datetime에는 원래 ISO 값을 유지할 수 있다. 없는 값은 일정 미정/기술 정보 없음으로 구분한다. 날짜 표시 시 임의의 UTC 변환으로 시간을 바꾸지 않는다.
