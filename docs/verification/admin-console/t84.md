# T84 상황별 조회 안내

사용자 요구: 비어 있는 채용/교육 공고를 조회 실패로 안내하지 않고 현재 종류·조건에 맞는 문구와 복구 행동을 제공한다.

## 관찰과 변경
기존 성공0건과 네트워크 실패는 분리되어 있었지만, 무필터 미등록과 필터 결과 없음은 동일 문구였다.

| 상황 | 안내/행동 |
| --- | --- |
| 무필터 전체0건 | 아직 등록된 공고가 없습니다. 새 공고가 등록되면 확인 가능 |
| 채용 탭0건 | 아직 등록된 채용 공고가 없습니다. 전체 공고 보기 |
| 교육 탭0건 | 아직 등록된 부트캠프·교육과정이 없습니다. 전체 공고 보기 |
| 교육 필터0건 | 선택한 조건에 맞는 부트캠프·교육과정이 없습니다. 분야/기술/모집/비용 조건 줄이기 |
| 채용 필터0건 | 선택한 조건에 맞는 채용 공고가 없습니다. 직무/기술/경력 조건 줄이기 |
| 검색어0건 | “검색어”에 해당하는 해당 종류가 없습니다. 철자/짧은 검색어 안내 |
| 첫 로딩 | 공고를 불러오고 있습니다 |
| 첫 요청 실패 | 공고를 불러오지 못했습니다. 서버/네트워크 가능성 및 재시도 |
| 다음 페이지 실패 | 다음 공고를 불러오지 못했습니다. 기존 결과 보존 및 같은 페이지 재시도 |
| 마지막 페이지 | 현재 조건의 공고를 모두 확인했습니다 |

필터/검색0건은 검색·필터 해제 버튼으로 현재 EMP/EDU 탭만 남긴 URL로 이동한다. header와 list의 기존 URL watch가 입력/칩/요청을 함께 갱신한다. 데이터가 없는 원인은 성공한 조회 범위까지만 판단하며, 필터0건을 전체 서비스 미등록으로 단정하지 않는다. 성공빈결과는 role=status, 실제 요청 실패만 role=alert/재시도다.

- Green: 공통 순수 TS `announcementEmptyState(filters)`가 메시지/행동을 결정, Vue는 현재 loading/error/list 상태에 따라 렌더링하고 라우팅만 담당. 대상18건 통과(`/tmp/demp-t84-green.log`).
- 오류패널에 empty-state CSS를 재사용하니 빈결과 존재 assertion이 실패했다. 의미에 맞게 list-error로 분리하고 시각 스타일만 공유했다.
