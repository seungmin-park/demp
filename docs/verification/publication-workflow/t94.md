# T94 · 모집 대상과 출처 중복

- Red: `/tmp/demp-t94-red.log` 같은 제목 다른 기관 등록이 409이고 모집 대상 저장값이 null. `/tmp/demp-t94-race-red.log` 같은 출처 동시 등록 두 요청 모두 201. `/tmp/demp-t94-front-red.log` 모집 대상 입력 없음.
- Green: NEW/EXPERIENCED/ANY/MIXED 명시 필드와 기존 경력 범위 fallback. 교육 기수·지원금 금액/조건을 연봉·교육비와 분리하고 채용 전환 시 제거한다. 제목 중복 판정 제거.
- 중복 키: URL host/default port/fragment/추적 query 정리 + 기관·기수 정규화의 SHA-256. 의미 있는 query는 유지. 요청 전 검사 + DB unique + 충돌409, 실패 업로드 보상 유지. 동시성 테스트는 실제 트랜잭션 201/409 및 최종 1행을 검증한다.
- 기존 데이터는 duplicate_key NULL로 보존하며 등록 시 NULL 행을 비교해 중복을 확인한다. 기존 중복은 자동 삭제하지 않는다. 대규모 데이터의 NULL 키 비교 비용은 배포 전 별도 검토·backfill 시 줄일 수 있다.
- 책임 검토: AnnouncementSourceKey는 출처 동일성만, Repository는 저장 자료 비교, 서비스는 사전 검사와 트랜잭션/보상, Announcement는 유형별 정보 분리를 담당한다. Vue는 입력·표시, API는 multipart 변환. JSON 기존 필드와 URL 계약 유지.
- 검증: B261 `/tmp/demp-t94-back-final.log`, F144 `/tmp/demp-t94-unit.log`, typecheck/lint/build `/tmp/demp-t94-{types,lint,build}.log` 모두 성공. 기존 교육/금액 테스트의 서로 다른 공고 fixture에 개별 URL을 부여했다.
