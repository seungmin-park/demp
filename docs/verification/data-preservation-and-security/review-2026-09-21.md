- MemberController 가입은 서비스에 입력을 전달하고 DTO를 반환한다. 서비스가 검증·암호화·저장 후 바로 DTO를 만들므로 저장한 회원을 다시 조회하지 않는다.
- 로그인 암호 확인·JWT 발급·MemberInfo 조립을 MemberService로 모았다. Controller는 HTTP 변환만 수행한다.
- QuestionService.findById는 이미 없는 질문에 ResourceNotFoundException을 던진다. Controller의 도달 불가능한 null 분기를 제거하고 공통 404 응답을 사용한다.
- 인증 ID로 실제 회원을 조회하는 코드에 남아 있던 임시 회원 TODO를 삭제하고 testMember를 author로 바꿨다.
- AnswerController의 List<QuestionAnswer>는 DTO의 JSON 배열이다. 정상적인 응답 계약이며 객체 wrapper 전환은 기존 후속 계획에 없었다. 프런트 계약을 바꾸는 변경은 하지 않았다.
- ContentSanitizer는 T13에서 추가한 저장 전 HTML 정화 책임이다. 질문·답변·공고에 공통 적용하며 jsoup 허용목록으로 script, 이벤트 속성, 위험 URI를 제거하고 허용 서식을 보존한다.

```text
회원 Controller → MemberService → 가입 저장 / 로그인 JWT → 응답 DTO
질문 Controller → QuestionService → 없는 자원 예외 → 공통 Advice의 404
HTML 입력 → ContentSanitizer → 저장 → 프런트 SafeHtml → 화면
```
