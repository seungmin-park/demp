[[Announcement-API]]
== Announcement API

NOTE: Phase 0에서 실행 검증한 계약은 목록·스크롤·없는 상세의 404 응답과 현재 multipart 등록 실패다.
정상 multipart 등록과 정상 상세 응답의 문서화는 T20에서 계약 수정과 함께 완료한다.
등록 DTO의 enum에 문자열용 검증 제약이 적용되어 있고, 상세 값 객체의 직렬화 계약도 정리가 필요하다.
이 문서는 등록 성공이나 정상 상세 응답을 보장하지 않는다.
목록의 `sort` 값은 수신되지만 현재 조회 쿼리에 적용되지 않는다(T32 예정).
