## 관찰 → 변경
카드가 minCareer=0이면 모두 신입 가능으로 표시하고 상세는 0년부터 숫자만 보여줬다. 관련 공고 DTO에는 유형과 연차가 없었다.

`AnnouncementScroll`에 announcementType/minCareer/maxCareer를 추가했다. 공통 `announcementAudience`가 기존 데이터 의미를 해석하고 `AnnouncementAudience`는 props만 받아 배지와 연차를 렌더링한다. 목록·상세·관련 공고 모두 동일 컴포넌트를 사용한다. 교육은 경력 표시를 숨긴다.

| 데이터 | 표시 |
| --- | --- |
| EDU | 교육 |
| EMP 0~0 | 경력 무관 |
| EMP 0~N | 신입·경력 / N년 이하 |
| EMP N~M | 경력 / N~M년 |
| EMP N~0 | 경력 / N년 이상 |
| 경력 정보 누락 | 채용 / 경력 정보 없음 |

기존 0 최대값은 상한 없음이다. 신입 전용을 식별할 별도 데이터는 없으므로 0~0을 신입으로 잘못 단정하지 않는다. 이미지와 저장 기능은 변경하지 않았다.
